01

Multimodal AI system

Risk Manager

AI-powered return fraud detection

Checks product returns for fraud on behalf of online stores. It looks at the customer's account signals and the return photos, then approves the return, sends a gentle nudge, or passes it to a human reviewer, so honest customers are not wrongly denied.

0.876PR-AUC, late fusion
0.447PR-AUC, tabular baseline
2,000sample synthetic benchmark
PythonLightGBMDINOv2FastAPIDocker

Hosting paused (free-tier limits). Code and demo video are linked.

Code Demo video

Architecture & key decisions

  • Defense-only return-fraud detection using a late-fusion meta-learner (LightGBM + DINOv2): 0.876 PR-AUC versus 0.447 for the tabular baseline on a synthetic 2,000-sample benchmark.
  • A LightGBM tabular scorer (account age, return velocity, COD status) routes low-trust cases to human review instead of denying them automatically, paired with a DINOv2 vision pipeline for substitution and empty-box fraud detection.
  • Three-way decision router (auto-approve, nudge, manual review) with a full audit trail and a circuit breaker for image upload failures; containerised with Docker (FastAPI backend and dashboard).

Shipment Risk Agent

Logistics risk intelligence platform

Predicts which shipments are likely to be delayed, across sea, road and air, in one dashboard. It combines live traffic, weather and news data with shipment records, and an LLM explains each risk, gives a mitigation strategy and recommends rerouting.

Architecture & key decisions

  • Full-stack platform (FastAPI, Supabase, React + Vite) processing 500+ shipment records through REST APIs.
  • Hybrid LightGBM scoring engine, trained on structured synthetic shipment-risk features, fusing 4 live data sources (TomTom, Open-Meteo, GDELT, Supabase) for delay-probability estimation, with sub-second latency in local testing.
  • Groq-powered LLM pipeline generating risk explanations, mitigation strategies and rerouting recommendations across 3 logistics modes; containerised with Docker.
03

Agentic backend

Goal-Stack Orchestrator

Multi-intent conversational backend

A chatbot backend that keeps track of what the user wants, even when they change topic or ask several things in one message. It splits the message into ordered actions, keeps unfinished goals on a stack, and recovers safely after a crash.

17pytest cases, crash-safe recovery
05node LangGraph state machine
02LLM router with fallback
PythonLangGraphGroqGemini FlashSQLiteNext.jsFastAPIpytest

Hosting paused (free-tier limits). Source code is linked.

Code

Architecture & key decisions

  • Models dialogue state as a goal stack, validated by a 17-test pytest suite for crash-safe recovery during non-linear, multi-intent conversations.
  • Dual-LLM router (Groq GPT-OSS-120B with a Qwen-27B fallback) splits messages into ordered actions inside a 5-node LangGraph machine with SQLite persistence and a Gemini Flash slot-filling agent.
  • Retries with exponential backoff (Tenacity) and concurrency locking, served through a Next.js and FastAPI stack.
